## 2. Main stem
* Start = spec `axis.curve_mm` (clicked axis; R3-1b and n_02 = vertical proxy, flag `axis_is_vertical_proxy`). Arc length s from its base (bottom).
* Candidates: surfels within 10 mm of the start curve **and** (not assigned to a leaf **or** thin), thin = local width ≤ 4 mm, local width = 4·√λ₂ of the positions of the surfels within 4 mm (λ₂ = second eigenvalue; < 8 neighbours → not thin). Count per 10 mm band of s reported.
* Centreline = start curve + 3-D displacement at control points every 10 mm of s (cubic interpolation in s; displacement at s = 0 fixed to 0). Objective: mean Huber(distance candidate → centreline, δ 2 mm) + 0.3 × mean distance(start-curve points every 1 mm → centreline) + curvature penalty 100 × Σ max(0, κ − 1/15 mm)² over 1 mm samples (radius of curvature ≥ 15 mm). L-BFGS-B, numerical gradient, start = 0 displacement, max 300 iterations. Declared now, not tuned.
* Band with < 20 candidates → its control point displacement fixed to 0 (`stem_kept_clicked_band`); < 100 candidates in the plant → whole centreline = start (`stem_kept_clicked`).
* Reported: max / median shift (1 mm samples), kept bands, top end: distance of the fitted top 10 mm to the nearest surfel, and whether the top 10 mm turns more than 60° from the plant's mean axis direction (`top_curls`).
* Nodes re-placed at the same arc length on the fitted centreline (internodes unchanged).

## 3. Compound leaves
Model leaf = the existing engine writer's leaf (`writers.leaf_polyline` + `add_leaf`): petiole 0.30 L at (φ, θ0), m = pairs(leaflets) rachis segments, elevation falling by Δθ with weights 1/(2m−1), 2/(2m−1); leaflet blades from the leaf's area (b) (e_*: no area → the pooled template area by rank of the old build, `pooled_area`, used **only** for the fitting geometry; written spec keeps area unavailable).
* Base point = node position on the fitted stem.
* **Level 1** (both formats): φ, θ0, Δθ, L per leaf. Bounds φ ∈ φ_skel ± 60°, θ0 ∈ [−60, 90], Δθ ∈ [0, 120], L ∈ [0.7, 1.3] × skeleton path length. Optimiser: scipy Powell with bounds, two starts — (a) current spec values (hand θ0, Δθ 32.764, skeleton φ and L), (b) same with θ0 = skeleton first-10-mm elevation (clipped into bounds); keep the lower cost. Deterministic.
* **Level 2** (engine only): from the Level-1 result, per-piece direction (azimuth, elevation) for the petiole and each rachis segment (2 + 2m parameters + L), bounds: each azimuth within φ_skel ± 60°, elevation [−60, 90] − cumulative; smoothness: angle between consecutive pieces ≤ 45° (penalty 100 × Σ max(0, angle − 45°)² in degrees, added to the cost). Powell, one start (Level-1 result). The engine writer accepts it: `to_engine_structure` writes each RachisSegment's own base/tip, azimuth and elevation (checked in the round trip). The B-model importer has one orientation/inclination per leaf → **Level 1 only**; its Δθ is not representable (the A1 adapter of the old build failed its check) → B-model geometry carries φ, θ0 (inclination = 90 − θ0) and L.
* **Objective (declared):** model points = rachis polyline sampled every 2 mm + for each leaflet blade 5 points (base, centre, tip, the two edge midpoints of the centre row); cost = mean Huber(distance model point → nearest surfel of this leaf's set, δ 2 mm) + 0.5 × mean distance(clicked-line points densified every 1 mm → model rachis polyline) + 0.5 × (1 − coverage), coverage = share of this leaf's surfels within 5 mm of any model point. Distances in mm.
* Leaf with < 30 surfels in its set → its set = the clicked line plus all non-stem surfels within 15 mm of the clicked line (`few_leaf_surfels`). One-click / model-completed leaf (no clicked direction) → not fitted (`not_fitted_model_completed`).
* **Gate per leaf (after the fit, on the Level-1 leaf; Level 2 checked the same way):** median distance model point → nearest surfel of **any** set ≤ 3 mm **and** ≥ 90 % of model points within 5 mm of any surfel. Level 1 fails → leaf keeps its current values in both formats (`fit_failed_kept_original`). Level 1 passes, Level 2 fails → engine uses Level 1 (`level2_failed_level1_used`). No second attempt.
* Spec: new values in the same keys (`azimuth_deg`, `theta0_deg`, `dtheta_deg`, `length_mm`, sources `fitted_to_surfels_ungraded`), previous values kept as `azimuth_prev_deg`, `theta0_hand_deg`, `dtheta_prev_deg`, `length_prev_mm`, `base_prev_mm`; Level 2 as `rachis_polyline_level2_mm`; stem as `axis.curve_mm` (fitted) + `axis.curve_prev_mm`.
