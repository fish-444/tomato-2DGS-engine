- 최대 건물중은 개체별 ×U(0.8, 1.2)입니다.
- 소엽 MID 250 °Cd와 K 0.014는 Twiggy Red 잎 생장(tm 271 / te 464 °Cd)에서 바꾼 값입니다(낮은 신뢰도).
- 과실 값은 문헌 기반 S1 스위치입니다(켜짐). 개화에서 과실까지 지연 0, 과실 수 상한 없음.

**식**
- 기관 목표 질량: M_target = M_max · (s(τ) − s₀)/(1 − s₀), s(τ) = 1/(1 + e^(−K(τ − MID))), s₀ = s(0), τ = 기관 열시간
- 과실 목표 질량: M_target = 1.16 · (g − g₀)/(1 − g₀), g = exp(−exp(−0.01127·(τ_f − 242.2))), τ_f = 개화 후 열시간
- 수요(gC): D = max(0, M_target − M) · CF / e
- 크기: 소엽 면적 A = M · SLA · f_SLA. 소엽 길이·폭 = √A × 윤곽 계수. 다른 기관 크기는 (M/M₀)^(1/3)배.

|---|---|---|

| α | 0.048 mol CO₂ mol⁻¹ 광자, 개체별 ×U(0.9, 1.1) | [문헌-타품종] Merlice |

| 탄소 비율 CF | 0.45 gC gDM⁻¹ | [가정] |
| 생장 효율 e | 0.75(생장호흡 25 %) | [가정] |
| SLA | 0.025 m² g⁻¹(250 cm² g⁻¹), 개체별 ×U(0.85, 1.15). **C5에서 맞춤** | [가정] → [맞춤] |
| 초기 예비탄소 | 0.06 gC | [가정] |
| 예비탄소 상한 비율 | 0.20(식물 건물중 대비) | [문헌-타품종] Butturini 버퍼 최대 ≈ 20 % |
| 억제 시작 | 상한의 50 % | [가정] |
| 예비탄소 하한(최소 상한) | 0.06 gC | 코드 |

**식(매일, 개체별)**
1. **총광합성(Thornley 비직각쌍곡선):** P = [αI + A_max − √((αI + A_max)² − 4θαI·A_max)] / (2θ). I = 소엽이 흡수한 광량 ÷ 소엽 면적. 일 총광합성(gC) = P · A · h · 3600 · 12.011×10⁻⁶. 소엽만 광합성하고, 줄기·엽축은 빛을 가리기만 합니다.
2. **유지호흡:** R_m = Σ M_기관 · 0.0005 · Δt(온도 반응 없음)
3. **예비탄소 상한:** cap = max(0.2·(CF·M_전체 + R), 0.06). 억제 계수 = 1(R ≤ 0.5·cap), 0.5·cap에서 cap까지 선형으로 줄어 0(R ≥ cap).
4. **받아들이는 총광합성:** G_acc = min(G · 억제 계수, 수용 한도). 수용 한도 = R_m + D + 0.2/0.8 · (CF·M + e·D) − R(최소 R_m + D + 0.06 − R). 버려지는 몫 G − G_acc = 억제된 광합성.
5. **배분:** 예산 B = R + G_acc − R_m, 배분 총량 F = min(max(0, B), D). 수요 × 축 가중치에 비례해 나누고, 수요를 넘는 기관은 수요에서 자릅니다.
6. **생장:** 구조 증가 ΔC = 배분 · e, 질량 증가 = ΔC / CF, 생장호흡 = 배분 · (1 − e). 남은 탄소는 예비탄소로 갑니다.
7. **장부:** R_시작 + G − 억제 − R_m − 구조 − 생장호흡 − R_끝 = 0(잔차 ~1e−16 gC)

**식**
- **서펠 흡수광(개념식):** Q_s = a · U(p_s) · Σ_방향 w_d · max(0, n_s·l_d) · T_d(s). 방향 가중 w_d는 바 직달 0.4와 산란 0.6을 나눕니다(산란 0.6을 전체 중 비율로 읽은 경우이며, 세션 정의 확인이 필요합니다). T_d는 그 방향 광선이 잎을 n장 지나면 0.07ⁿ, 줄기에 맞으면 0입니다. n_s는 평활 법선입니다.
